# 幻觉治理典型案例（3 个）

> 第 3 周交付物：从 120 题评估中挑选条件漏判、表格数值编造、无依据兜底各一个案例。


## 案例 1：条件漏判 — Q7「优秀学生的评选条件是什么？」

### 期望答案要点

期望条件（7 条）：遵守宪法和法律、遵守学校规章制度、诚实守信、道德品质优良、学习刻苦、积极参加社会实践、积极参加志愿服务。期望数值：前 20%。

### 优化前（朴素 prompt）

> 优秀学生评选条件：评选比例不超过 3%；当学年获得优秀学生二等及以上奖学金；身体素质达到《国家学生体质健康标准》良好及以上。

**问题**：只覆盖了 1/7 条件（"身体素质良好"），遗漏了"遵守宪法和法律""诚实守信""道德品质优良"等 6 条基本条件。朴素 prompt 没有强制逐条列出并列条件，模型倾向于只挑最"特殊"的条件回答。

### 优化后（约束 prompt + 校验 + 兜底）

> 依据《浙江工业大学本科学生荣誉称号评定及管理办法》第十一条：
> 1. 获当学年优秀学生二等及以上奖学金
> 2. 身体素质达到《国家学生体质健康标准》良好及以上等级
>
> 评定比例不超过学生人数的 3%。

**分析**：优化后答案列出了 2 条具体条件并标注了来源 [2]，结构更清晰。但仍有缺失——期望条件中的"遵守宪法和法律""诚实守信"等属于奖学金/荣誉评定的通用基本条件（第四条），而非优秀学生特有的第十一条。模型检索到的 context 偏向"特殊条件"条款，未覆盖"基本条件"条款。

**根因**：检索层面，"优秀学生评选条件"的 query 召回了第十一条（特殊条件）但未召回第四条（基本条件），导致模型即使想逐条列出也无素材。这是**召回不足**而非生成幻觉。

**改进方向**：对"评选条件"类问题，检索应同时召回"基本条件"条款和"具体条件"条款。

## 案例 2：表格数值缺失 — Q3「计算机学院 2025-2026 学年省政府奖学金有多少名额？」

### 期望答案要点

期望数值（3 个）：23 级 35 人、24 级 19 人、25 级 52 人。

### 优化前（朴素 prompt）

> 参考资料中未明确列出省政府奖学金的具体名额数字。建议您直接咨询学院教务办获取当学年省政府奖学金的具体名额分配数据。

**问题**：表格数据（名额分布 PDF）实际在知识库中，但检索未召回相关 chunk，导致模型无法回答。

### 优化后（约束 prompt + 校验 + 兜底）

> 依据提供的参考资料，未在现行政策中找到关于计算机学院 2025-2026 学年省政府奖学金具体名额的明确信息。建议咨询教务处获取准确数据。

**分析**：优化后正确触发了兜底话术（D1），没有编造数值。但核心问题是**检索未命中**——名额分布 PDF 是表格密集型文档，表格 chunk 在 BM25 和向量检索中都表现较弱（表格关键词密度低，语义表征不完整）。

**根因**：表格 chunk 的检索召回率不足。这是已知的表格子集难点（表格 Top1 从 86.96% 经 Rerank 提升至 91.30%，但仍有 ~9% 的表格题未命中）。

**改进方向**：表格 chunk 的表征增强（如表头下沉、面包屑回填已在 chunker 中实现），以及 Rerank 对表格的补偿能力仍有提升空间。

## 案例 3：无依据兜底 — Q87「研究生奖学金怎么申请？」

### 期望行为

该题为负样本（negative_sample=true），知识库仅收录本科生教务文档，不包含研究生政策。系统应正确拒答，不编造研究生奖学金信息。

### 优化前（朴素 prompt，无兜底机制）

> （前置兜底检查命中关键词"研究生"，直接返回兜底话术）
>
> 未在现行政策中找到依据，建议咨询教务处。

**说明**：优化前虽然无完整兜底机制，但评估脚本中的 `pre_llm_fallback_check` 检测到"研究生"关键词后直接拦截，未调用 LLM。

### 优化后（约束 prompt + 校验 + 兜底）

> 未在现行政策中找到依据，建议咨询教务处。
>
> [兜底] 超范围问题（命中关键词：研究生）

**分析**：优化后 D1 兜底机制完整运行：
1. 检索返回了若干文档（可能包含本科生奖学金政策）
2. `pre_llm_fallback_check` 检测到"研究生"关键词 → 触发前置兜底
3. 直接返回统一话术，未调用 LLM，节省 API 开销

**验收**：8 条负样本全部正确兜底（100% 拒答率），包括：研究生奖学金、转专业、辅修学位、毕业设计、社团、宿舍、补考、出国留学。

**改进方向**：当前兜底依赖关键词匹配（18 个超范围关键词），存在漏检风险（如"硕士论文"未包含"研究生"但也是超范围）。后续可考虑引入分类器或 LLM 意图识别来增强超范围检测。

## 总结

| 案例 | 类型 | 优化前问题 | 优化后表现 | 根因 |
|------|------|-----------|-----------|------|
| Q7 优秀学生评选 | 条件漏判 | 只列 1/7 条件 | 列 2 条但仍有缺失 | 召回不足（未召回基本条件条款） |
| Q3 省政府奖学金名额 | 表格数值 | 未找到数值 | 正确兜底 | 表格 chunk 检索召回弱 |
| Q87 研究生奖学金 | 超范围兜底 | 关键词拦截 | 完整兜底机制 | 知识库不覆盖研究生政策 |

**核心结论**：
1. 约束型 Prompt（C2）有效提升了条件列出的结构化程度，但受限于检索召回质量
2. 原文校验（C3）能捕获数值编造，但当前综合幻觉率指标设计偏高（C3 校验数叠加到分子）
3. 兜底机制（D1）对负样本 100% 有效，关键词匹配策略简单但可靠
